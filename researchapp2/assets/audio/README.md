# Audio Files Setup Guide

## 📁 File Structure
Place your audio files in the following structure:

```
assets/audio/learning_journeys/
├── dsa/
│   ├── episode_1/
│   │   └── audio.mp3
│   ├── episode_2/
│   │   └── audio.mp3
│   └── ... (episodes 1-6)
├── science_mysteries/
│   ├── episode_1/
│   │   └── audio.mp3
│   ├── episode_2/
│   │   └── audio.mp3
│   └── ... (episodes 1-5)
├── psychology/
│   ├── episode_1/
│   │   └── audio.mp3
│   ├── episode_2/
│   │   └── audio.mp3
│   └── ... (episodes 1-5)
└── finance/
    ├── episode_1/
    │   └── audio.mp3
    ├── episode_2/
    │   └── audio.mp3
    └── ... (episodes 1-5)
```

## 🎧 Audio Requirements
- **Format**: MP3 (recommended) or AAC
- **Quality**: 128kbps minimum, 320kbps maximum
- **Length**: 7-9 minutes per episode (optimal for learning)
- **Naming**: audio.mp3 in each episode folder

## 🔧 For Development Testing
If you don't have audio files yet, you can:

1. **Use placeholder audio**: Record simple "Episode 1", "Episode 2" announcements
2. **Use text-to-speech**: Generate temporary audio using online TTS tools
3. **Use sample audio**: Download royalty-free audio clips for testing

## 🚀 For Production
1. **Professional recording**: Use quality microphones and editing software
2. **Script writing**: Create conversational, engaging content
3. **Sound design**: Add background music and sound effects
4. **Quality control**: Test audio on different devices

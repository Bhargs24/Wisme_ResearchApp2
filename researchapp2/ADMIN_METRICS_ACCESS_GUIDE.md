# 🔐 **ADMIN METRICS ACCESS GUIDE**

## 🚪 **How to Access Essential Metrics (Admin Only)**

### **Step 1: Access Admin Dashboard**
1. **Run your app**: `flutter run -d windows`
2. **Navigate to admin**: Go to `/admin` route in your app
3. **Sign in**: Use your admin email: `bhargavr098@gmail.com`

### **Step 2: Export Essential Metrics**
Once in the admin dashboard:
1. **Click the download icon** (top right) 
2. **Choose export type**:
   - **Essential Metrics (JSON)** - Complete research data
   - **Essential Metrics (CSV)** - Spreadsheet format
   - **Research Summary** - Key findings text
   - **Raw Data Export** - All collected data

### **Step 3: Use Exported Data**
- Data is **copied to clipboard**
- **Paste into**: Excel, Google Sheets, research documents
- **JSON data**: Use for analysis tools, Python/R scripts
- **CSV data**: Open directly in Excel/Google Sheets
